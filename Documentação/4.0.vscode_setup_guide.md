## 🏗️ Passo a Passo Completo

### Etapa 1: Criar o Projeto

```bash
# 1. Abrir terminal/prompt de comando
# 2. Navegar até onde quer criar o projeto
cd C:\Projetos  # Windows
# ou
cd ~/projetos   # Linux/Mac

# 3. Criar pasta principal
mkdir melhorador-fotografico
cd melhorador-fotografico

# 4. Inicializar Git

```

```bash
# Abrir projeto no VSCode

# Ou manualmente: File > Open Folder > Selecionar a pasta
```

### Etapa 3: Criar Ambiente Virtual

**No Terminal do VSCode (Ctrl+`):**

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

**Configurar VSCode para usar o ambiente:**
1. `Ctrl+Shift+P` → "Python: Select Interpreter"
2. Selecionar `./venv/bin/python` (ou `.\venv\Scripts\python.exe` no Windows)

### Etapa 7: Criar Código Principal

**1. Criar `src/melhorador_fotografico.py`:**
*Cole o código da classe principal do artifact anterior*

**2. Criar `main.py`:**
```python
#!/usr/bin/env python3
"""
Sistema Avançado de Melhoria Fotográfica
Entry point principal da aplicação
"""

import sys
import os
import argparse

# Adicionar src ao path
sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'src'))

from melhorador_fotografico import MelhoradorFotografico

def main():
    parser = argparse.ArgumentParser(
        description='Sistema Avançado de Melhoria Fotográfica',
        formatter_class=argparse.RawDescriptionHelpFormatter,
        epilog="""
Exemplos:
  python main.py                           # Processamento padrão (médio)
  python main.py forte                     # Intensidade forte
  python main.py medio minhas_fotos saida  # Pastas customizadas
  python main.py --help                    # Ver ajuda completa
        """
    )
    
    parser.add_argument(
        'intensidade', 
        nargs='?', 
        default='medio',
        choices=['leve', 'medio', 'forte'],
        help='Intensidade do processamento (padrão: medio)'
    )
    
    parser.add_argument(
        'pasta_entrada',
        nargs='?',
        default='fotos',
        help='Pasta com fotos originais (padrão: fotos)'
    )
    
    parser.add_argument(
        'pasta_saida',
        nargs='?',
        default='fotos_melhoradas',
        help='Pasta para fotos processadas (padrão: fotos_melhoradas)'
    )
    
    parser.add_argument(
        '--auto',
        action='store_true',
        default=True,
        help='Ativar ajuste automático (padrão: ativo)'
    )
    
    parser.add_argument(
        '--no-auto',
        action='store_true',
        help='Desativar ajuste automático'
    )
    
    args = parser.parse_args()
    
    # Ajusta auto_ajuste baseado nos argumentos
    auto_ajuste = args.auto and not args.no_auto
    
    print("🎨 Sistema Avançado de Melhoria Fotográfica v2.0")
    print("=" * 50)
    
    try:
        melhorador = MelhoradorFotografico()
        melhorador.processar_pasta(
            args.pasta_entrada,
            args.pasta_saida, 
            args.intensidade,
            auto_ajuste
        )
        
        print("\n✅ Processamento concluído com sucesso!")
        
    except KeyboardInterrupt:
        print("\n⏹️ Processamento interrompido pelo usuário")
        sys.exit(1)
        
    except FileNotFoundError as e:
        print(f"\n❌ Pasta não encontrada: {e}")
        print("💡 Dica: Certifique-se que a pasta existe ou crie uma pasta 'fotos' com suas imagens")
        sys.exit(1)
        
    except Exception as e:
        print(f"\n❌ Erro inesperado: {e}")
        print("💡 Execute com 'python main.py --help' para ver as opções")
        sys.exit(1)

if __name__ == "__main__":
    main()
```
